# Lucky Slot

사용자가 입력한 선택지 중 하나를 슬롯머신 연출과 함께 무작위로 골라주는 웹 애플리케이션입니다. 검정 배경과 오렌지색 포인트, 빈티지 스타일의 슬롯머신을 사용했습니다.

## 사용법

1. 선택지 입력 칸에 항목을 입력합니다.
2. **ADD +** 버튼을 눌러 목록에 추가합니다. 빈 입력이나 공백만 입력한 내용은 추가되지 않습니다.
3. 목록에서 **REMOVE**를 눌러 필요 없는 항목을 삭제합니다.
4. 선택지가 하나 이상 있을 때 **PULL TO PLAY** 버튼을 누릅니다.
5. 레버와 릴 애니메이션이 끝나면 선택지 중 하나가 결과로 표시됩니다.
6. **PLAY AGAIN**을 눌러 다시 추첨할 수 있습니다.

게임 실행 중에는 선택지를 변경하거나 다시 실행할 수 없습니다. 페이지를 새로고침하면 선택지 목록이 초기화됩니다.

## 코드 및 파일 구조

```text
.
├── index.html              # 페이지 구조와 콘텐츠
├── css/
│   └── style.css           # 레이아웃, 색상, 글꼴, 반응형 및 애니메이션 스타일
├── js/
│   └── app.js              # 선택지 관리, 게임 흐름, 릴 애니메이션, 무작위 추첨
└── assets/
    └── CloisterBlack.ttf   # 제목에 사용하는 글꼴
```

현재 `assets` 폴더에는 이미지 파일이 없으며, 제목용 글꼴 파일이 포함되어 있습니다.

## 실행

`index.html`을 웹 브라우저에서 열면 사용할 수 있습니다. GitHub Pages에 배포할 때는 저장소의 **Settings → Pages**에서 배포 브랜치와 폴더를 설정하세요.
